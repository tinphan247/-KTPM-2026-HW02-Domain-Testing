⚠️ ROOT CAUSE ANALYSIS — BUG-FR01-08
Vi phạm nghiêm trọng tiêu chuẩn an toàn bảo mật SEC-01 và chuẩn OWASP A02: Mật khẩu người dùng được ghi thẳng xuống bảng users dạng văn bản thuần (Plaintext 100%). Bất kỳ ai có quyền truy cập vào file database.sqlite hoặc lỗi SQLi đều đọc được toàn bộ mật khẩu của khách hàng.
✓ RECOMMENDED FIX (PATCH)
const bcrypt = require('bcrypt');
const hashedPassword = await bcrypt.hash(password, 10);
db.run("INSERT INTO users (name, email, password) VALUES (?, ?, ?)", [name, email, hashedPassword], ...);
